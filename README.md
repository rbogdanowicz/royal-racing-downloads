# Royal Racing

Corridas de kart para Windows, com garagem, personalização e diferentes divisões.

## Instalar

[**Baixar Royal Racing para Windows 64 bits**](https://github.com/rbogdanowicz/royal-racing-downloads/releases/latest/download/RoyalRacing-win-Setup.exe)

Instale uma vez e abra o atalho **Royal Racing**. O iniciador mostra as notas da versão e baixa novas atualizações automaticamente. A instalação espera o jogo fechar, sem interromper sua corrida. Nas preferências do iniciador, você pode escolher a atualização manual.

Quem usava o ZIP precisa instalar este instalador uma vez para passar a receber atualizações. Garagem, saldo, peças e recordes anteriores do Windows são preservados. O progresso do navegador é separado.

[Novidades e versões](https://github.com/rbogdanowicz/royal-racing-downloads/releases)

Este instalador ainda não possui assinatura digital de editor; o Windows pode exibir um aviso ao abri-lo.

## Arquivos das versões

- `RoyalRacing-win-Setup.exe`: instalador do jogo.
- `releases.win.json` e o pacote `.nupkg`: arquivos usados pelo atualizador.
- `release-notes.md`: novidades da versão.
- `SHA256SUMS.txt`: hashes para conferência de integridade.

Este repositório contém apenas a distribuição do jogo e suas notas. O código-fonte é mantido em um projeto privado.
